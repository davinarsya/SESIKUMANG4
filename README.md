# Cek Jadwal Sesi Kumang — Elektro 2025

Website statis untuk mencari jadwal sesi makan bersama berdasarkan NRP.

## Isi repository
- `index.html` — website lengkap beserta data peserta.

## Deploy menggunakan GitHub Pages
1. Buat repository baru di GitHub.
2. Upload `index.html` dan `README.md` ke root repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
6. Tunggu proses deployment selesai. GitHub akan menampilkan URL website di halaman Pages.

Website ini tidak membutuhkan framework, build command, atau server backend.
